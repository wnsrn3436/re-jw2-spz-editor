# SPZ 파일 포맷

쥬라기원시전2의 유닛 이미지 파일(SPZ) 분석 자료다.

## 헤더 (32바이트)

모든 값은 4바이트 리틀엔디언이다.

| 오프셋 | 내용 |
|---|---|
| `0x00` | 가로 픽셀 수 |
| `0x04` | 세로 픽셀 수 |
| `0x08` | 중점 x |
| `0x0C` | 중점 y |
| `0x10` | 충돌점 x |
| `0x14` | 충돌점 y |
| `0x18` | 헤더를 뺀 데이터 크기 |
| `0x1C` | 미상 |

중점과 충돌점은 음수로 저장된다.

## 픽셀 데이터

`0x20` 부터 시작하며 한 행씩 이어진다. 행은 그 행의 인코딩된 길이 2바이트로 시작하고 그 뒤에 픽셀이 온다. 이 편집기는 그 2바이트 중 하위 1바이트만 쓰고 읽을 때는 건너뛴다. 픽셀은 팔레트 인덱스 1바이트로 적히는데, 인덱스 0은 투명이고 뒤에 반복 개수 1바이트가 따라온다. 예를 들어 `00 0B` 은 투명 픽셀 11개가 연달아 있다는 뜻이다. 유닛 그림은 투명 영역이 넓어서 이 방식만으로도 크기가 많이 준다.

## PNT 팔레트

0번 항목이 투명색, 1번 항목이 그림자색이다. `0x3D4` 부터 4바이트 간격으로 열 개가 플레이어 색상이다. 항목 하나는 R, G, B, 0 의 4바이트다.
